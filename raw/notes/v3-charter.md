# v3 헌장 — 소유자 6대 철학 (2026-08-25 확정)

출처: 소유자와의 v3 재설계 대화(2026-08-25). v2 대비 신규/변경 결정 포함.

1. **투명래퍼 인터프리터** — 오픈코드가 갖는 훌륭한 하네스를 투명래퍼로 씌워 인터프리터 계층을 만든다. 사용자가 일기쓰듯 남겨도 인터프리터가 스키마화하고 최적의 오픈코드 하네스에 접속·호출한다 = 100% 오픈코드 활용. startup inventory는 산문이 아니라 실행 코드로 구현한다.

2. **도메인 지식 보완** — 프로젝트 고유 지식은 오픈코드 자체만으로 해결되지 않는다. 위키 지식과 로컬 MCP(사실상 DB)로 보완한다.

3. **클래리파이 선행** — 사용자 의도가 불분명하면 곧바로 스키마하지 않는다. 최초 의도를 명확히 구체화한 뒤 스키마를 생성해야 의도가 스키마에 충분히 포함되고 뒷단 그릴링 폭이 줄어든다. "이미 전달된 상태에서 AI가 판단해 선택지를 묻는" 후행 게이트는 순서가 틀렸다. confidence 같은 측정 불가능한 내부 지표 대신 결정론 체크리스트(필수 필드)를 쓴다.

4. **Echo 게이트 (v3 신규, 강제)** — 의도가 명확하더라도 사용자 지시로 작업을 수행한다는 내용을 요약해 제시하고 확인한 뒤 진행한다. 초보자는 지시도·전문용어도·해법도 모르지만 자기 의도의 요약은 판단할 수 있다. 모델에 따라 하는/안 하는 편차가 있으므로 모델 성격이 아니라 타입과 코드로 강제한다.

5. **비핵심 부속물** — 해시라인·워크트리 등은 팔란케이스 하네스의 핵심이 아니다. v3 미포함. 필요 시 git 이력(v2 HEAD: b14f1bbcfd574590a6cd13b5b662fa3e994bca2e)에서 회수.

6. **강제 위임·컨텍스트 보존** — 서브에이전트 강제 위임으로 오리지널 컨텍스트를 보존한다. 최초 설계된 AGENTS.md/스킬/스펙은 최초 로딩 후 KV캐시에 상주함을 전제로 한다.
